## 追加費用のご相談が必要になりうる項目

依頼の範囲は今回すべて反映済みです。以下は、さらに機能を広げる場合の選択肢です。

- **管理画面つきの更新（CMS化）**：現在の更新方法は GitHub 上でのファイル編集です。ブログのような管理画面（WordPress・microCMS など）から更新したい場合は、別途構築が必要です。
- **Instagramの最新投稿の自動表示**：現在は、紹介したい投稿のURLを登録する方式です。最新投稿を自動で並べるには、Instagram API の連携か外部ウィジェット（月額費用が発生するものがあります）が必要です。
- **お知らせ記事の個別ページ化**：お知らせを1件ずつ独立したページ（写真・本文つき）で公開したい場合。
